# TypeVibrator

> 📳 **LSPosed / LibXposed 模块** | 为 *微信输入法*、*豆包输入法*、*讯飞输入法*、*Gboard* 提供更丰富的震动选项。

我很喜欢 vivo 输入法那个双段震动，遂制作此模块给主流输入法也弄一个两段震动。

**需要 LibXposed API 102**（LSPosed 1.9.3 及以上），以及 **Android 13（API 33）及以上**。

| 输入法 | 包名 | 状态 |
| --- | --- | --- |
| 微信输入法 | `com.tencent.wetype` | 支持（自定义波形偏弱，见已知问题） |
| 豆包输入法 | `com.bytedance.android.doubaoime` | 支持 |
| 讯飞输入法 | `com.iflytek.inputmethod` | 支持；`.oem` / `.miui` 等定制版需在 LSPosed 里**手动勾选作用域** |
| Gboard | `com.google.android.inputmethod.latin` | 支持（含同包名的 Gboard Go） |

> 模块没有桌面图标。所有设置都在输入法设置页的侧边圆形按钮里，见[输入法内的设置入口](#-输入法内的设置入口)。

## 📝更新日志

### v1.4.0 (1400) · 纯模块形态

- **形态重构**：模块不再有桌面图标与独立 Activity，移除 launcher、Remote Preferences / Remote Files 通道与绑定 Service。设置页作为**寄生 Activity 运行在输入法进程内**，直接读写该输入法自己的配置目录
- **技术底座**：入口换成 YukiHook 1.5.0 + KSP 自动生成 `META-INF/xposed`，资源包 ID 设为 `0x64` 避免与宿主资源冲突
- **配置**：三个配置文件（`settings.json` / `haptic.json` / `ui.json`）收敛为宿主目录下的**单快照** `files/haostoo/config/state.json`；写入走 `AtomicFile` + `fsync`，`FileObserver` 监听热更新，内容损坏时改名 `state.bad.<时间戳>.json` 留证并按默认值运行；旧配置一次迁移到 `config/legacy/`
- **设置页**：根级三板块「**首页 / 配置 / 设置**」（miuix `FloatingNavigationBar`）。首页是框架连接状态与版本信息概览；配置页是按下/抬起震动；设置页含颜色模式、配置导入导出、调试日志、帮助、关于
- **热重载**：适配 API 102 `ModuleLifecycle`，覆盖安装模块后无需重启输入法即可生效；设置页处于前台时拒绝重载
- **修复**：豆包输入法点击入口打不开设置页 —— 代理 Activity 改用不在栈中的页面，避免复用从未绘制成功的 Activity 记录
- **文案**：全量资源化（简体中文 / English）

### v1.5.0 (1500) · 新增讯飞输入法与 Gboard

- **新宿主**：接入**讯飞输入法**（`com.iflytek.inputmethod`，按前缀覆盖 `.oem` / `.miui` 等定制版）与 **Gboard**（`com.google.android.inputmethod.latin`，Gboard Go 同包名）

- **proxy**：讯飞用 `LauncherSettingsActivity`（其设置页是 `singleInstance`，不能当 proxy），Gboard 用 `launcher.LauncherActivity`

### v1.2.2 (1225) · 2026-08-29

- **修复**：设置页与 hook 的配置路径不一致问题，配置读写统一指向宿主（输入法）目录，修改设置能正确生效
- **新增**：配置热重载、外观主题、调试与日志

## 🏖️食用方法

### 安装

- 通过 **LSP仓库/本仓库** 下载模块并安装。在 LSPosed 管理器中启用模块、勾选作用域（**微信输入法** / **豆包输入法** / **讯飞输入法** / **Gboard**）后，重启一次目标应用即可。讯飞的定制版（`.oem` / `.miui`）不在默认作用域里，需要手动勾选对应应用。此后**更新模块本体不需要再重启输入法**（走 API 102 热重载，若设置页正在前台会推迟到关闭后）。
- 模块鲁棒性还行，兼容其他模块和部分修改版。但对于***“共存版”、“改包名版”***，因包名改变会导致无法使用，可拉取源码自行编译。

### 配置

- 打开输入法的**设置页**，点击屏幕侧边悬浮的圆形按钮进入模块设置。模块**没有桌面图标**。
- 根级底栏为「**首页 / 配置 / 设置**」三项：
    - **首页**：框架连接状态（是否连上、框架版本、API 版本）、版本信息（应用 / 框架 / Android / 系统）、宿主概览、注入状态；
    - **配置**：按下震动、抬起震动、恢复默认配置、重载输入法；
    - **设置**：颜色模式、配置导入 / 导出、调试日志、帮助文档、关于（仓库 / 酷安 / 频道 / 赞助）。
- **按下震动：** 打字按下时的震动策略； **抬起震动：** 手指从屏幕抬起时的震动策略。

- ##### 震动风格
    - 无震动：顾名思义
    - 系统预设：Android 系统中现有的最多 20 种震动风格
    - 简单自定义：自定义震动时长与强度的震动
    - 自定义波形：自定义具体震动曲线的高级震动，在「配置」页点击 **设置波形** 进入图形化编辑器（曲线预览 + 有效波段数 + 逐段时长/强度），参阅 [高级配置](#高级配置)

- ##### 其他设置
    - 颜色模式：浅色 / 深色 / 跟随系统
    - 恢复默认设置：一键恢复默认配置（带确认对话框）
    - 配置导入 / 导出：导出为 JSON 文件，或从文件选择器导入；导入时校验格式，非法文件会被拒绝
    - 调试日志：调试输出开关、清除日志、打包导出
    - 帮助文档、关于（仓库主页 / 酷安主页 / 频道连接 / 赞助作者）

- **重载输入法：** 用于在**重启输入法**后才能生效的场景（例如更换了震动目标类）。需授予本模块 root 权限（通过 ``am force-stop`` 停止目标进程）。

- 配置保存在各输入法自己的数据目录：`/sdcard/Android/data/<宿主包名>/files/haostoo/config/state.json`，一个宿主一份，互不影响。可用「导出配置」备份。

### 高级配置

自定义波形可直接在设置页**图形化编辑**：在「配置」页将按下/抬起风格选为**自定义波形**后，点击 **设置波形** 进入编辑器。

点击某方向的「设置波形」只会编辑该方向（按下或抬起）的波形。编辑器包含：

- **有效波段数**（2~8）：该卡片唯一的波段数量来源；
- **曲线预览**：平滑拟合曲线（仅作视觉预览，实际震动按离散数值执行），点击曲线节点可打开该波段的底部调整面板；
- **波段编辑行**：按有效波段数生成，逐段填写时长（ms）与强度（0~255）；第 1 段时长依 Android 文档固定为 0 且灰显只读。

默认预填一套四段波形（与内置默认值一致）。缩小波段数后再放大，会保留本次编辑中隐藏的波段值；新增波段按当前曲线插值生成非零初值，不会补零。点击**保存**才写入配置并生效；**取消**或返回不会写入。

如需从旧版迁移，把旧的 `config.xml` 放进宿主的配置目录后首次启动即可自动迁移；也可以准备一个 `customhaptic.json`，通过「配置导入」选择文件导入。

当震动风格为自定义波形时，对应的按下（Down）或抬起（Up）震动将根据此配置震动。通过自定义曲线理论上可以模拟绝大多数应用和系统触觉反馈的震动风格，包括但不限于部分定制输入法提供的模拟机械键盘震动。

#### 配置示例

导出的配置文件形如：

```json
{
  "schema": 3,
  "host": "com.bytedance.android.doubaoime",
  "state": {
    "settings": { "down_mode": 1, "up_mode": 0 },
    "waveform": {
      "down": { "timings": [0, 10, 40], "amplitudes": [0, 140, 60] },
      "up": { "timings": [0, 40], "amplitudes": [0, 120] }
    }
  }
}
```

##### 字段说明

**down：** 按键按下时触发的震动波形。

**up：** 按键抬起时触发的震动波形。

**timings：** 震动时间数组，单位为毫秒（ms）。数组中的每个元素表示该阶段持续的时间。

**amplitudes：** 震动强度数组。取值范围：**0 ~ 255**。数值越大，震感越强。

##### 示例：

```json
"timings": [0, 6, 6],
"amplitudes": [0, 140, 60]
```

表示：

| 阶段 | 时长     |强度|
| -- | ------ |---|
| 0  | 立即开始   |开始|
| 1  | 持续 6ms |140|
| 2  | 持续 6ms |60|

### CustomHaptic 配置规则

##### 1. 两个数组长度必须一致

正确：

```json
{
  "timings": [0, 6, 6],
  "amplitudes": [0, 140, 60]
}
```

错误：

```json
{
  "timings": [0, 6, 6],
  "amplitudes": [0, 140]
}
```

##### 2. timings 第一个元素必须为 0

正确：

```json
"timings": [0, 6, 6]
```

错误：

```json
"timings": [5, 6, 6]
```

##### 3. timings 值必须非负，amplitudes 值必须位于 0~255 之间

正确：

```json
"amplitudes": [0, 120, 255]
```

错误：

```json
"amplitudes": [0, 300, -1]
```

##### 4. 数组不能为空

错误：

```json
"timings": []
```

#### 配置建议

- 不同设备的马达性能不同，相同配置的实际震感可能存在 **巨大差异**。想获得较正常的体验至少需要线性马达。转子马达难以高精度控制，效果很差。

- 不同系统对于震动调用的频率和精度也有限制。因此 timings 分段不建议过短过复杂，过于复杂精细的曲线可能被系统截断或降级，导致实际震动效果与配置效果有出入。

- 因此总时长控制在几十毫秒，分 2~4 段是比较甜点的选择。

#### [Android 官方文档](https://developer.android.com/reference/android/os/VibrationEffect#createWaveform(long[],int[],int))

自定义波形震动基于 `VibrationEffect.createWaveform()` 实现。

## 🔓输入法内的设置入口

- 在微信输入法 / 豆包输入法各自的「设置」页里，屏幕侧边会悬浮一个可拖动的圆形按钮；点它直接打开该宿主的震动设置。
- 按钮松手后自动吸附到最近侧边，位置按宿主分别记住。
- 设置页是**寄生在输入法进程里的模块 Activity**：读写的永远是当前输入法的配置，因此不存在「跨宿主修改」这回事，每个输入法只管自己。
- 模块只支持 LSPosed（LibXposed API 102）；不提供 LSPatch / NPatch 等免 Root 修补支持。
